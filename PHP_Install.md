# Installation de PHP 8.3 (Windows, NTS x64)

## 1) Télécharger
- Archive : [php-8.3.24-nts-Win32-vs16-x64.zip](https://windows.php.net/downloads/releases/php-8.3.24-nts-Win32-vs16-x64.zip)

## 2) Préparer l’arborescence
Créez le dossier : `C:\php\8.3`

## 3) Extraire l’archive
Décompressez le fichier ZIP téléchargé **dans** : `C:\php\8.3`

## 4) Placer le `php.ini`
Copiez votre fichier `php.ini` à cet emplacement : `C:\php\8.3\php.ini`

## 5) Ajouter PHP au `PATH`
1. Ouvrez **Paramètres système avancés** → **Variables d’environnement…**
2. Dans **Path** (utilisateur ou système), cliquez sur **Modifier**.
3. Ajoutez une nouvelle entrée : `C:\php\8.3`
4. Validez toutes les fenêtres.
